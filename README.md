PollZone – Minimal Community Polling Web App
📌 Project Description :

PollZone is a modern and lightweight community polling web application built using HTML5, CSS3, and Vanilla JavaScript. The platform allows users to create polls, participate in anonymous voting, and visualize results in real-time using interactive charts — all without requiring any backend server or authentication system.

The application is designed to work completely inside the browser using the LocalStorage API, making it fully offline-capable and easy to deploy on static hosting platforms such as GitHub Pages
 and Netlify.

PollZone focuses on simplicity, accessibility, responsiveness, and user experience while maintaining vote integrity through browser-based duplicate vote prevention techniques.

🚀 Features :
1. Create custom polls with multiple options
2. Anonymous voting system
3. One vote per browser using LocalStorage validation
4. Real-time result updates
5. Interactive Pie & Bar charts using Chart.js
6. Poll categories (Opinion, Decision, Survey)
7. Active and closed poll management
8. Poll expiration timer
9. Percentage and vote count display
10. Search and filter functionality
11. Export poll results as CSV
12. Dark / Light theme toggle
13. Responsive modern UI
14. CSS animations and smooth transitions
15. Fully offline browser-based functionality

🛠 Technologies Used :
1. HTML5
2. CSS3
3. Vanilla JavaScript
4. LocalStorage API
5. Chart.js
6. CSS Animations

💡 How It Works :
* User creates a poll
* Poll data is stored in LocalStorage
* Users can vote anonymously
* Votes update charts instantly
* Browser stores vote history to prevent duplicate voting
* Data remains saved even after page refresh
